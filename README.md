# Sistem Persuratan

Sistem informasi persuratan berbasis Laravel untuk mengelola administrasi surat secara digital.

## Fitur

- Autentikasi pengguna
- Dashboard
- Manajemen Surat Masuk
- Manajemen Surat Keluar
- Disposisi
- Arsip Digital
- Pencarian & Filter
- Pagination
- Upload Dokumen
- Integrasi Google Drive

## Tech Stack

- Laravel 9
- MySQL
- Tailwind CSS
- Bootstrap Icons
- Google Drive API
